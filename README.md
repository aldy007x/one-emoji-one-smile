One emoji, and nothing else: 🫶 (heart hands) — the single emoji most likely to make a stranger smile. A small gift of warmth offered outward: a heart made by two hands, instantly readable, universal, chosen rather than default, and right for a stranger — gratitude and goodwill with no romance, flirtation, or hug an unknown person did not ask for.

## Run it

```sh
python3 main.py
```

Writes exactly one emoji to `/output/entry.txt`.
